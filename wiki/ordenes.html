Ordenes de entrada y salida

Las ordenes controlan compras, recepciones y consumos internos del almacen.

Orden de entrada

  1. Crear orden seleccionando proveedor y productos.
  2. Capturar cantidad y precio unitario.
  3. Autorizar orden antes de recibir partes.
  4. Antes de autorizar se muestra ultima compra por producto: proveedor, fecha y precio.
  5. Al ingresar partes se validan QR o SKU y precios reales.
  6. Al pasar a RECIBIDA, la base de datos suma inventario mediante trigger.

Orden de salida

  1. Seleccionar articulos disponibles.
  2. Capturar area obligatoria y observaciones.
  3. Validar QR o SKU de cada producto.
  4. Aprobar salida para confirmar consumo.
  5. Al pasar a CONFIRMADA, la base de datos descuenta inventario mediante trigger.
  6. El sistema registra costo PEPS, unitario y subtotal.
Validacion QR: en entradas y salidas se puede leer SKU o ID del producto para confirmar que la parte recibida o entregada corresponde a la orden.

PEPS en salidas

  • El sistema consume lotes disponibles por orden de entrada mas antigua.
  • Si un detalle historico no tiene costo, los reportes usan respaldo por costo unitario, costo de reposicion o ultima compra.
  • El sistema evita crear lotes legacy cuando el producto ya tiene lotes de compra registrados.
  • La salida guarda costo PEPS promedio por producto y subtotal.
