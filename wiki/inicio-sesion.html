Acceso al sistema

El sistema requiere autenticacion para operar modulos internos y APIs de gestion web.

Inicio de sesion

  1. Abrir la URL del sistema.
  2. Capturar usuario y contrasena asignados.
  3. El sistema identifica el perfil ADMIN, ALMACEN o CONSUMIDOR.
  4. El menu muestra solamente las opciones disponibles para ese perfil.
  5. El perfil CONSUMIDOR ingresa directamente a la captura rapida de salida.

Cierre de sesion

  • Cerrar sesion al terminar turno o al usar equipos compartidos.
  • No compartir credenciales.
  • Solicitar altas, bajas o cambios de perfil al administrador.

Permisos y seguridad

  • Los endpoints web protegidos requieren una sesion activa.
  • Las pantallas y acciones administrativas verifican el perfil del usuario.
  • El API movil usa token por encabezado X-CRORAM-Mobile-Token.
  • Las acciones de ordenes validan perfil, estado y cantidades escaneadas.
  • Las operaciones concluidas no pueden aplicarse por segunda vez.
