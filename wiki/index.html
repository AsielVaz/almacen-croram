Sistema de almacen Croram

Referencia de funcionalidades operativas y cambios aplicados al sistema de almacen, inventario, ordenes, reportes, QR y API movil.

Modulos principales

  • Articulos: catalogo, inventario, ubicacion, costos, QR e historial.
  • Ordenes de entrada: compra, autorizacion, validacion QR, recepcion y PEPS.
  • Ordenes de salida: consumo por area, observaciones, validacion QR, costos PEPS y aprobacion.
  • Reportes: inventario, entradas, salidas, consumos, compras, sugeridos y obsoletos.
  • Catalogos: familias, proveedores, areas y usuarios.
  • API movil: consulta y cierre de ordenes desde app externa.

Cambios recientes integrados

  • Inventario ya no se duplica al recibir entradas.
  • Salidas muestran costo PEPS, unitario y subtotal.
  • Reportes calculan valor de inventario y costos con respaldo de ultima compra.
  • Etiquetas QR imprimen descripcion del articulo junto al SKU.
  • Lista de articulos usa paginacion por API y busqueda en tiempo real.
  • API movil permite buscar, validar, listar pendientes y finalizar ordenes.

Flujo operativo recomendado

  1. Registrar catalogos base: familias, areas, proveedores y usuarios.
  2. Dar de alta articulos con nombre, SKU, familia, descripcion, ubicacion, unidad, inventario y costo.
  3. Generar QR de articulos cuando se requiera identificacion fisica.
  4. Crear ordenes de entrada para compras y autorizar antes de ingresar partes.
  5. Validar productos con QR o SKU antes de recibir o entregar.
  6. Consultar reportes para revisar inventario, consumos, compras y costos.
