Articulos, existencias, costos y QR

El modulo de articulos concentra la informacion base de cada producto y su existencia actual.

Datos del articulo

  • SKU o codigo interno. Si no se captura, el sistema genera un consecutivo.
  • Nombre, descripcion y ubicacion fisica.
  • Familia, subfamilia y unidad de medida.
  • Condicion obligatoria: NUEVO o USADO.
  • Estado ACTIVO o INACTIVO para controlar su uso en nuevas operaciones.
  • Inventario actual o inicial y costo por pieza.

Busqueda y listado

  • La lista usa paginacion por API para cargar mas rapido.
  • El buscador filtra por nombre, SKU, descripcion o ubicacion.
  • Se puede cambiar el numero de articulos por pagina.
  • La ubicacion se muestra en el reporte de articulos para facilitar conteos fisicos.
  • Cada registro disponible permite editar o consultar historial segun el perfil.

Costo por pieza

  • En alta y edicion se captura directamente el costo correspondiente a una pieza.
  • El valor capturado no se divide entre la existencia actual.
  • Este costo se utiliza como referencia del articulo y como respaldo cuando no existe un costo de compra aplicable.
  • Las salidas confirmadas conservan el costo calculado mediante PEPS.

QR de articulos

  • Se pueden seleccionar articulos desde la lista y generar un PDF termico o carta.
  • Ambos formatos imprimen un QR de 4x4 cm.
  • Las etiquetas se generan exclusivamente en blanco y negro.
  • Debajo de cada etiqueta se imprime una regla tipo flexometro y se conserva margen al final de la hoja.
  • La etiqueta muestra el nombre del articulo; si no existe, utiliza la descripcion.
  • El QR codifica el SKU para validar las piezas sin capturar manualmente el ID del articulo.

Historial e inventario

  • El historial muestra entradas y salidas asociadas al articulo.
  • El inventario se calcula con la existencia actual.
  • Los lotes PEPS guardan cantidad inicial, cantidad disponible y costo unitario.
  • Los saldos historicos sin lote de compra cuentan con lote de apertura para mantener cobertura PEPS.
