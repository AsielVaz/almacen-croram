API para aplicacion movil

El sistema cuenta con un endpoint para app movil que permite consultar ordenes, validar escaneos, listar pendientes y finalizar operaciones.

Endpoint

POST https://almacen.grupocroram.com/api/mobileOrdenes.php
Header: Content-Type: application/json
Header: X-CRORAM-Mobile-Token: croram-mobile-dev-2026-cambiar

Acciones disponibles

  • health: valida disponibilidad del API.
  • listarPendientes: muestra ordenes pendientes de ingresar o aprobar.
  • buscarOrden: obtiene informacion y detalle de una orden.
  • validarEscaneos: compara escaneos contra productos esperados.
  • finalizarOrden: registra entrada o confirma salida despues de validar.

CORS

  • El endpoint responde con Access-Control-Allow-Origin: *.
  • Acepta preflight OPTIONS.
  • Permite encabezados solicitados por navegador, incluyendo token movil.

Listar pendientes

{
  "accion": "listarPendientes",
  "limite": 50,
  "tipo_orden": "",
  "texto": ""
}

Buscar orden

{
  "accion": "buscarOrden",
  "tipo_orden": "entrada",
  "id_orden": 35
}

Validacion y cierre

  • Cada pieza requerida debe contar con un escaneo antes de finalizar.
  • El operador utiliza el QR o SKU; no necesita capturar manualmente el ID del articulo.
  • Entrada: requiere orden AUTORIZADA y que no tenga lotes ya registrados.
  • Si un precio final de recepcion supera al autorizado, la API conserva la recepcion como PENDIENTE_AUTORIZACION_RECEPCION.
  • Salida: requiere validacion completa y que la orden se encuentre pendiente de confirmar.
  • El flujo movil utiliza las mismas reglas de estados, inventario y PEPS del sistema web.

Respuesta de validacion

  • validarEscaneos informa cantidades esperadas, escaneadas, faltantes y excedentes.
  • finalizarOrden rechaza la operacion cuando falta al menos una unidad por validar.
  • Una recepcion con diferencia de precio responde requiere_autorizacion: true.
  • Las ordenes ya concluidas se protegen contra una segunda aplicacion.
