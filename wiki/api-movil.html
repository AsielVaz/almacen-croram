API para aplicacion movil

El sistema cuenta con un endpoint para app movil que permite consultar ordenes, validar escaneos, listar pendientes y finalizar operaciones.

Endpoint

POST https://almacen.grupocroram.com/api/mobileOrdenes.php
Header: Content-Type: application/json
Header: X-CRORAM-Mobile-Token: croram-mobile-dev-2026-cambiar

Acciones disponibles

  • health: valida disponibilidad del API.
  • listarPendientes: muestra ordenes pendientes de ingresar o aprobar.
  • buscarOrden: obtiene informacion y detalle de una orden.
  • validarEscaneos: compara escaneos contra productos esperados.
  • finalizarOrden: registra entrada o confirma salida despues de validar.

CORS

  • El endpoint responde con Access-Control-Allow-Origin: *.
  • Acepta preflight OPTIONS.
  • Permite encabezados solicitados por navegador, incluyendo token movil.

Listar pendientes

{
  "accion": "listarPendientes",
  "limite": 50,
  "tipo_orden": "",
  "texto": ""
}

Buscar orden

{
  "accion": "buscarOrden",
  "tipo_orden": "entrada",
  "id_orden": 35
}

Finalizar orden

  • Entrada: requiere orden AUTORIZADA, validacion completa y que no tenga lotes ya registrados.
  • Salida: requiere validacion completa y que la orden no este CONFIRMADA.
  • Los escaneos pueden usar SKU o ID de producto.
  • El flujo movil usa las mismas reglas de inventario y PEPS del sistema web.
